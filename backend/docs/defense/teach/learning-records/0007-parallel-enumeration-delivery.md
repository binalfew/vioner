# Parallel-structure delivery — the four-item enumeration

Slide 5 is the first slide that uses an explicit numbered enumeration ("one... two... three... four..."). Saying parallel-structured items in sequence is its own delivery skill — done badly it sounds like a teacher reading bullet points; done well it has rhythm and weight variation. This lesson introduces the technique and applies it to the four-challenge structure.

## Implications

- Future slides with explicit enumerations (slide 7 — four gaps, slide 8 — five components, slide 22 — five contributions close) reuse this technique.
- Each item in the enumeration should be *internally different* — examples, statistics, quote, complication — so the panel hears varied substance under the parallel form.
- Pre-empted attacks on this slide are mostly forward-references: "is class imbalance really 78%" (slide 17 metrics), "why DISTRICT?" (slide 20 confusion matrix), etc. Drill the answers but don't deliver them on slide 5 itself.
