The four LLM disqualifiers
  1. Closed weights Vendor can update silently; reproducibility breaks.
  2. Per-call cost 30k articles/yr × fee = recurring budget line.
  3. No auditability Can't trace inference — non-negotiable for AU early-warning.
  4. Data sovereignty Conflict metadata to US API = non-starter for AU member states.

"Why not GPT-4?" — full answer

"Four operational disqualifiers — closed weights, per-call cost, no auditability, data sovereignty. LLMs remain a credible future baseline to compare against, but not a substitute for an auditable on-prem system."

If pushed on Masakhane

"Masakhane is excellent for African-language coverage. But it stops at the model boundary. VioNER adds the operational layer: violent-event entities, KB validation, taxonomy, deployable platform."

If pushed on ICEWS/GDELT head-to-head

"Different output schemas — CAMEO codes vs 5W1H records. Head-to-head F1 isn't meaningful. Backup B9 compares against generic BERT NER on entity-tag overlap. VioNER produces a different shape of output that the analyst actually needs."
