Slide 7 — Four operational gaps (90 s)

Opener: "The four operational gaps — the heart of the contribution. I state them operationally, in terms of what the analyst CAN'T get today." (pause)
Four gaps — verbatim
Gap 1 · structured 5W1H · 15 s "Gap one: fast, structured, role-distinguished 5W1H output. ACLED has it slowly; automated tools give flat or wrong-shape output."
Gap 2 · rare-entity recovery · 15 s · LAND "MISS" "Gap two: automated tools recover dates and locations but miss victims, casualties, action verbs."
Gap 3 · trust + canonicalisation · 15 s "Gap three: output isn't sanity-checked against world knowledge or canonicalised across surface forms."
Gap 4 · deployable · 15 s "Gap four: no system an analyst can actually deploy and run without ML expertise."
Defence · why 4 not 3 · 20 s · SLOW THE TWO EXAMPLES "If asked 'why four and not three?' — no existing system fills all four, and each is independently necessary for the analyst's job. A perfectly structured output that arrives too late is useless; a fast output that misses victims is useless."
Operational framing — the new craft skill
Technical (wrong here)"Plain CE fails under imbalance."
Operational (right here)"Analysts don't see victims, casualties, action verbs."

Rule: if the sentence describes what the technology is missing → technical. If it describes what the user can't do → operational. Slide 7 is all operational.

Pre-loaded interrupts
1
Couldn't gaps 1 and 4 collapse?
Gap 1 = output shape; gap 4 = system shape. ACLED has 1 but not 4 (structured but no analyst can run it). Generic deployable NER has 4 but not 1 (anyone can run it but output is flat). Fail independently.
2
Aren't gaps 2 and 3 both about quality?
Gap 2 = recall (find them at all). Gap 3 = validation (check what's found). Recall without validation → hallucinations. Validation without recall validates nothing.
3
Is this just a checklist? Where's the real contribution?
The integration is the contribution. Each gap → one component. Each component has precedent individually. What's new: closing all four simultaneously, evaluated end-to-end.
